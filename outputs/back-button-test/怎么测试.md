# 返回按钮怎么测试

先使用 `01-标准返回测试-A和B.zip`。仅用于预览测试，不送审。

1. 上传至小红书工作台，在平台模拟器打开，再用手机扫码。
2. 点“开始 A”，点“进入第二页”，然后按**小红书顶部系统返回按钮**。观察是回到“第一页”还是直接退出小工具。
3. 退出后重新打开，点“开始 B”，重复同样操作。
4. 如果第二页能回第一页，再试“进入第三页”，看能否连续回到第二页、第一页。
5. 如果系统按钮会退出，可另外再开一轮，点“对照：网页内返回”。记录这个按钮能否回上一页。不要把它的结果当作系统返回已通过。

建议先测平台模拟器，再分别在Android和iOS真机验证；普通电脑浏览器的返回不能代表小红书原生按钮。

## A/B 都不行时再测 C

上传 `02-多页返回实验-C.zip`，打开后点“进入第二页”，再按小红书顶部返回。

这个包是故意验证两个HTML之间的跳转，不是正式发布包。若平台拒收，或第二页打不开，也记录为结果，不要修改平台限制来强行通过。

每种方式请退出再重新打开，避免上一轮记录干扰。如果重新扫码仍停在第二页，请先截图说明，不能把重新打开后的页面当作返回成功。
