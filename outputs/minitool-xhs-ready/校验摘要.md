## 已实现

- 共用现有正式源码，从专用构建步骤输出小工具包，不直接改写网页入口与网页存储/下载实现。
- 输出同时提供「保存到相册」和「发作品」。拼豆图纸、镜像图纸、无标注图共用多选，默认仅拼豆图纸，零选禁用。所选图片一起带入同一篇原生笔记。
- 两种输出都先保存草稿，包括只选无标注图。保存失败阻止输出，保留当前编辑与旧记录。相册部分失败时，在当前输出会话内重试只继续未完成图片。
- 发布取消或失败保留草稿；仅 `postNote:ok` 回执后按草稿 ID 和保存版本 ID 记录提交状态。回执不表示审核通过，本地状态写入失败也不会自动重复发布。
- 平台 Storage 替代浏览器数据库与最近颜色缓存。单草稿使用不可变分片，分片完成后提交小指针，再清理旧分片；失败不覆盖旧指针，不回退浏览器存储。原图、像素、3 个手动版本、最近颜色与自动恢复语义继续保留。
- 经典外置脚本，目标 Chrome 61；内联 import map、模块入口和网页下载调用未进入交付脚本。示例数据随经典脚本交付，不依赖运行时 fetch。
- 像素识别使用包内 classic Worker，客户端低于 9.53、构造失败或系统回收时走既有主线程回退，保留过期任务隔离。
- 样式展开层叠层与嵌套，补充实际用到的选择器、逻辑属性、动态高度、颜色、Flex 间距、宽高比和独立变换的兼容路径。现代函数置于合适的增强规则中；容器安全区变量与 viewport-fit 已接入。旧内核仍须实测，不能仅凭转换声称 Chrome 61 已通过。
- 修正小工具包中未命名图纸保存后仍提示未保存的判断；明确空名称与旧数据缺失名称的区别。
- ZIP 排除实验页、原始素材、开发配置、README、manifest、source map 和编译器。许可证正文保存在包内 `licenses.json`。

## 必须由平台和真机补验

1. 上传本 ZIP 后，在创服平台模拟器检查打开、资源加载、选图、预览、编辑和保存。
2. 使用同一个 ZIP 分别在 Android 和 iOS 真机扫码验证。检查相册权限允许/拒绝、1/2/3 张图片、部分保存失败、原生发布页取消与提交，以及重新打开小工具后的草稿和历史。
3. 真实双指缩放、平移、画笔/橡皮、撤销、后台恢复、软键盘、安全区、大图生成时间和内存仍待实测。
4. Chrome 61 / Android 8.1 CSS 和完整交互未实测。构建目标与回退存在不表示旧内核验收通过。
5. Storage 单 key 1 MB、总计 10 MB。保存需要新旧两代的临时空间；大原图或多份草稿可能触达容量限制，此时明确报错，不缩减原图/历史或伪造保存成功。设备清理缓存或卸载后不保证草稿保留，也不提供跨设备同步。
6. 未手动清理提交结果不明确的分片，优先保留恢复可能；极少数接口异常可能留下不可见孤立分片，占用空间。未通过静默删除历史记录回收空间。
