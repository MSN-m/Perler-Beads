# Perler Beads

## 助手交接与归档规范 (Handover & Archive Spec)
为了确保跨 AI 模型协作的一致性及 GitHub 同步后的结构完整，请遵循以下规范：

1. **一键归档指令**：当接收到“一键归档”指令时，必须分析会话并生成总结文档。
2. **强制归档路径**：所有新生成的总结文档必须存放于 `docs/archive/` 目录下。
3. **命名格式**：`docs/archive/DEVELOPMENT_SUMMARY_YYYYMMDD_HHMM.md`。
4. **内容要求**：提取功能变更、文件修改清单、已知 Bug 现状及后续计划。

请其他 AI 助手在处理此项目时严格遵守上述目录结构。
