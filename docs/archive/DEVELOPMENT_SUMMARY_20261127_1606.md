# 开发归档｜示例库、各端原图按钮与小工具 iPad 适配

归档时间：2026-11-27 16:06（Asia/Shanghai）。上一份：DEVELOPMENT_SUMMARY_20261120_1117.md。本次归档记录截至当前聊天的最终状态；历史阶段被下列最终决策覆盖。

## 已完成与最终决策

### 示例图纸库

- 小工具示例拆分为六份精简JSON，catalog管理引用；每组构建为独立经典脚本，按需加载，主包不内嵌全部图纸数据。加载失败重试、快速切组隔离、收起释放、组内分批、点击才创建编辑像素均已接入。
- 最初实现一个默认展开组和其他折叠组，名称可后改。用户后续要求首页示例区域暂按原样，因此当前catalog使用顶层patterns，六张平铺，不显示“最新图纸”或分组标题。分组能力保留，未来UI确认后才启用。
- 更新方法在docs/MINITOOL_EXAMPLE_LIBRARY.md：文件夹分组ZIP，每张图纸JSON；告知组名、顺序、默认展开组、替换/保留策略。只提取当前图纸，不导入原图、历史或用户草稿；分组仍占离线包总空间，Git同步不等于更新发布端。
- 关于示例体积、50/100张压力、分组和Git高频同步曾讨论，未形成真机容量/耗时基准；本归档不补造数值。

### 原图按钮（各端）

- 有原图时“对比原图”，展开后“收起原图”。无原图“没有原图”，置灰且原生disabled/aria同步，事件入口也检查原图，不能仅靠样式拦截。

### iPad 首页

- 仅小工具采用平板首页布局：上传/我的草稿位于宣传语下方，取消固定底栏；横屏四列、竖屏三列，最大内容宽1100px。手机原底部双按钮与普通网站保持。
- 复用原按钮节点和事件，适配触控/宽屏iPad判断；草稿弹窗旋转保持，示例区最终仍六张平铺。
- 我的草稿为纯白色且无投影；恢复品牌/图标呼吸、错开延迟和滚动滞后。遵守减少动态效果及草稿弹窗暂停规则。
- 应用户要求在布局预览中加入柯基、草稿1、草稿10三份模拟草稿，仅供视觉测试，刷新还原。

### iPad 上传页

- 横竖屏统一左图右设置；图纸设置和图片调整同级上下展示，取消标签切换；确认、撤回、取消在图片下方横排。
- 小工具构建复用手机上传语义：长边40/70/100、4/8/12/16色、默认40格4色、短边随裁剪比例，名称/品牌弹窗与三项调色保持。
- 裁剪确认历史、取消/撤回区别、预览返回保留、退出确认及生成加载保护沿用；普通网站和手机不迁移平板布局。

### iPad 预览页

- 仅同步头部为上传页样式：白色圆角栏、居中标题、左返回/右粉色确认；其余预览区域尚未整体重新设计。
- 用户发现露出下层原图与面板，补全预览层定位和不透明背景。随后恢复PAD原逻辑隐藏/禁用的像素画入口，仅对小工具构建放开PAD限制，原有特征识别门槛保留。
- 用户要求效果按钮保持横排，已明确指定四列，横竖屏同一行。

## 待办与未实施方案
