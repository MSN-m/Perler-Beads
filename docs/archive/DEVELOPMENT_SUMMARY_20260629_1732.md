# Perler Beads 开发归档 - 2026-06-29 17:32

## 本轮主要变更

### 1. 手机端生成流程拆分
- 将手机端上传后的流程拆为：
  - 确认范围
  - 生成设置
  - 生成预览 / 选择效果
- 确认范围阶段改为独立卡片式布局。
- 确认范围阶段只保留：
  - 重新选择图片
  - 确认范围
- 生成设置阶段保留：
  - 重新裁剪
  - 移除图片
  - 生成设置项
  - 生成预览

### 2. 手机端裁剪交互优化
- 修复卡片化后裁剪框与图片显示区域错位的问题。
- 裁剪坐标改为基于 `getBoundingClientRect()` 计算，避免嵌套绝对定位导致偏移。
- 裁剪框支持拖拽四边和四角。
- 手机端点击框外不再重新框选，避免误触。
- 扩大手机端裁剪拖拽热区。

### 3. 生成设置顺序调整
- 三端统一调整设置项顺序为：
  - 拼豆品牌 / 规格
  - 像素密度
  - 数量限制

### 4. 图纸名称字段
- 新增 `AppState.patternName`。
- 生成设置中新增图纸名称输入框。
- 不填写时使用占位/兜底名：`未命名图纸`。
- 新上传图片、移除图片时清空图纸名称。
- 保存草稿时记录图纸名称。
- 恢复草稿时恢复图纸名称。
- 草稿箱重命名时同步 `patternName`。
- 普通带标注导出图纸顶部显示图纸名称。
- 镜像带标注导出图纸顶部显示 `图纸名称（镜像）`。
- 导出文件名优先使用图纸名称。
- 原始无标注导出暂不加标题，避免破坏纯素材/透明图用途。

### 5. 顶部头部初步调整
- 已生成图纸后显示顶部通栏。
- 左侧改为：
  - 图纸名称
  - 设置按钮
- 右侧保留：
  - 颜色清单
  - 草稿
  - 导出
- 手机端草稿按钮文案缩短为 `草稿（n）`，避免顶部拥挤。

### 6. 设置面板重新应用机制
- 已生成图纸后，设置面板不再显示 `生成预览`。
- 新增 `应用设置` 按钮。
- 点击 `应用设置` 时统一弹出确认提示。
- 确认后进入效果预览，由用户点击 `使用这个效果` 后才覆盖当前图纸。
- 原始算法生成按钮强制隐藏，避免误出现。

### 7. 设置面板稳定性修复
- 修复已生成图纸后拖动像素密度会导致状态跳转的问题。
- 新增：
  - `AppState.pendingGridWidth`
  - `AppState.pendingGridHeight`
- 已生成图纸后调整密度只记录为待应用设置，不立即修改当前图纸尺寸。
- 点击 `应用设置` 确认后才提交待应用尺寸并重新生成预览。

### 8. 质量检查报错修复
- 修复 `RangeError: Invalid array length`。
- 原因：调整密度后 `gridWidth/gridHeight` 与旧 `pixelData` 长度不匹配，质量检查仍继续扫描。
- 修复：
  - `hasWorkbenchPattern()` 必须校验 `pixelData.length === gridWidth * gridHeight`。
  - `analyzeQualityIssues()` 增加尺寸不匹配保护。
  - 密度变化导致未生成状态时清空旧图纸、预览缓存和质量检查状态。
