# 开发归档｜手机页面底色、MARD 品牌选择与预览缩放

归档时间为 2026-11-16 22:00（Asia/Shanghai）。上一份归档为[手机裁剪、图纸预览与加载反馈](DEVELOPMENT_SUMMARY_20261116_1658.md)。本轮工作区以提交 `dc8e8ee` 为基线。

## 本轮改动

### 手机页面标题与底色

- 手机「预览图纸」生成效果面板的顶部两角改为 20px，与「图纸设置」面板一致。
- 手机「上传图片」「预览图纸」「保存与分享」的标题与内容滚动区分开，顶部使用白底。首页限制竖向回弹，首页和编辑器的标题仍在各自内容区外。
- 用户在上传页反馈设置面板下方露出渐变。裁剪区保留渐变，图纸设置和图片调整的底部到固定操作栏统一为白色。检查了长屏有剩余空间和短屏滚到底两种情况。
- 用户截图确认「预览图纸」标题上方变深的位置是 iPhone 系统状态栏。移动端白色主题与页面底色之外，预览标题栏改为固定在视口顶边，供 Safari 取色。内置浏览器确认标题贴顶和内容区可滚动，未验证 iPhone 的系统状态栏颜色。[WebKit 取色说明](https://bugs.webkit.org/show_bug.cgi?id=301756#c2)

### 三端品牌选择

- 正式工作台的 PC、PAD、手机统一只允许选择 MARD，保留各档 MARD 规格。Perler、Hama、Artkal 仍显示，置灰并禁用。新上传和示例图片的生成入口使用 MARD。
- 非 MARD 旧草稿恢复时保留原品牌、调色板、色号与像素，仍可编辑、保存和导出。正式工作台之外的旧版、实验页面及调色板数据保留。

### 手机和 PAD 预览双指缩放

- 两个触点都从图纸预览区开始才缩放图纸，以两指中心定位，最小为适配大小，最大为 8 倍。超出预览框的部分裁切在框内。标题、生成效果和按钮区域的双指操作拦截页面缩放，单指滚动与点按照常。
- 同一次预览切换效果时保留缩放。返回设置、进入编辑或退出触控布局时清理预览变换。缩放仅作用于预览画布的显示，不写入编辑状态、图纸像素、草稿或导出数据。

## 验证与已知问题

- 隔离内置浏览器的 390×360 和 506×1074 视口验证了标题定位、设置及图片调整底色、按钮可达和预览页内容滚动。另在 1280px 视口回归 PC 预览布局。
- 390px 手机、900px PAD 和 1280px PC 视口验证了禁用品牌、选择 MARD 规格及确认生成，并用合成 Perler 草稿验证原品牌恢复、编辑和生成导出图片。
- 用模拟双指事件验证图内、图外和跨区起手，覆盖单指不拦截、缩放范围、预览裁切、效果切换、返回后重开和进入编辑像素一致。PC 预览回归通过。现有 Node 测试 143 项全部通过。
- 本机浏览器使用直接项目入口 `http://127.0.0.1:8765/`。手机同 Wi‑Fi 可访问 `http://192.168.0.107:8765/`。预览服务使用独立的静态副本，与项目工作区的本轮页面改动同步。未使用个人 Chrome 或刷新用户正在编辑的页面。
- iPhone Safari 状态栏取色及回弹仍待实机复验。手机、PAD 的真实双指手势和原生整页缩放抑制仍待实机确认。此前归档中的草稿横滑、连续裁剪、大图加载及非规则像素画复验也未关闭。
- 本轮未改动或专项回归固定标尺。PC 顶部遮挡与数字密度修正仍待浏览器验收。PAD 和手机仍未同步固定边缘、坐标跟随、刻度密度和对照边界，既有标尺的触控可用性仍待核查。
