## 2. 功能变更

### 2.1 质量检查交互调整

质量检查不再使用展开面板或弹窗。

当前逻辑：

- 点击“质量检查”按钮后，在画布上显示问题区域。
- 再次点击关闭检查显示。
- 画布被平均划分为 3 x 3 固定区域。
- 每个有疑似问题的区域显示轻量边框和右上角数量徽标。
- 徽标数量表示该固定区域内实际疑似问题格子的数量，而不是检测窗口数量。
- 疑似格子会用更浅的高亮标出。
- 编辑、删除、撤回、取消、确认后会刷新检查结果。

已移除：

- 质量检查弹窗。
- 质量检查侧边面板。
- 尝试合并/展开查看等复杂交互。

### 2.2 质量检查检测逻辑

当前检查以固定区域聚合展示，底层检测包含：

- 小块孤立区域：同色连通区域过小。
- 局部颜色碎片化：滑动窗口中颜色数量偏多、主色占比偏低时标记疑似稀有色格子。

注意：

- 区域划分是展示层聚合，不是按自然连通区域切分。
- 检测结果会按疑似格子的实际坐标归入 3 x 3 固定区域，避免跨区域误计数。

### 2.3 工具指针优化

工作台编辑阶段新增了不同工具状态的鼠标指针：

- 取色类：吸管指针。
- 填色类：画笔指针。
- 删除类、移除底色、背景移除：橡皮指针。
- 边缘调整：十字准星。
- 普通浏览和画布平移：保留原来的抓手。

实现方式：

- 在 `src/ui.js` 中集中根据当前状态更新工作台指针。
- 使用内置 SVG cursor，避免新增图片资源文件。
- 不改变现有画布拖拽、填色、删除等业务逻辑。

### 2.4 取色填色流程简化

已移除“图纸 / 原图”吸色来源开关。

当前交互：

- 进入“取色填色”后，图纸上未选颜色时点击色块即从图纸吸色。
- 吸到颜色后，图纸区域变为填色状态，点击或框选会填入当前颜色。
- 打开“原图对照”后，原图区域随时可以点击重新吸色。
- 从原图吸色后会自动匹配到当前拼豆调色板中的最近颜色。
- 工具栏文案统一为“取色填色”或“填色 色号”。

已移除：

- `workbench.html` 中的 `fill-source-toggle`、`fill-source-canvas-btn`、`fill-source-original-btn`。
- `src/main.js` 中对应按钮事件绑定。
- `src/features/adjust.js` 中旧的 `setFillSourceMode()` 入口。

## 5. 当前已知风险

- 自定义 SVG 鼠标指针在不同浏览器和高 DPI 屏幕下可能存在清晰度或热点偏移差异。
- 原图对照现在随时可吸色，需要验证拖动原图对照时不会误触吸色；当前代码已有 `comparePreviewDidDrag` 抑制逻辑。
- 质量检查仍是启发式检测，适合作为提示，不应被理解为绝对错误判定。
- 3 x 3 固定区域适合总览，但对超大图纸可能仍显粗，需要后续考虑 4 x 4 或可配置区域数。

## 6. 后续待办：当前颜色跟随提示

用户已提出后续需求：希望鼠标指针能显示当前选中的颜色。

建议实现方式：

- 不直接动态修改系统 cursor 图标颜色。
- 在鼠标旁边增加一个小型浮动提示。
- 吸到颜色后显示当前颜色色块和色号。
- 进入取色填色、色盘填色、原图对照吸色时统一复用。
- 未选颜色时不显示色块，仅保留吸管指针。
- 移出工作区、退出编辑模式、取消/确认编辑时隐藏。

推荐第一版效果：

- 鼠标右下角显示 12-16px 小色块。
- 色块旁显示当前色号，例如 `H18`。
- 根据颜色亮度自动选择浅/深边框或文字，保证可读性。

难度评估：

- 只显示当前颜色小浮标：低。
- 增加色号和明暗自适应：中低。
- 让 SVG cursor 本身实时染成当前颜色：中等，且兼容性和维护成本更高，不建议第一版采用。
