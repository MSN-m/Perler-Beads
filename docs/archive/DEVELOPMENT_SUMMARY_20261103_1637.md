## 2. 单格排查：已确认定义与范围

### 2.1 检测规则

- 只检测实际拼豆格，不检测透明格。
- 中心格周围3×3中的八个位置，任意一个有效邻居色号相同，就不算落单，包括斜角同色。
- 超出图纸边界的位置不参与判断，不能跨行绕回；透明格不是一种候选颜色。
- 仅单格；不接入两三格小块、散碎颜色区域等检查。
- “待检查”不等于设计错误。眼睛、高光、文字等可能有意使用单格，用户可以忽略。

### 2.2 入口与本轮会话

- 编辑页顶部增加“排查”入口；手机将入口浮在画布右上，避免进一步挤压已有头部操作。
- 面板显示待检查、已修改、已忽略统计，当前序号/总数、原色号和1起始列/行。
- 面板顶部可拖动，位置限制在视口内。普通排查面板不是模态弹窗，允许使用现有画笔、吸管、橡皮以及画布缩放/平移。
- 打开排查先通过现有关闭路径收起色板，再切到安全拖动工具；连续绘制/擦除或平移期间不启动排查。
- 镜像方向、图纸身份、网格尺寸变化，或离开编辑时结束旧排查，清理旧目标和修复预览遮罩，不能把旧位置用于新图纸。

### 2.3 逐处处理

1. 打开后定位第一处；上一处/下一处或全部列表中的条目均可跳转。
2. 每次跳转自动居中目标并采用适合局部处理的缩放，描边标记当前格，保留附近上下文。
3. “固定镜头”指每次切换目标自动定位，不是锁死镜头；定位后仍可手动平移和缩放。
4. 用户用原编辑工具修改。列表动态判断原目标是否已经改色/删除，或因邻居变化不再孤立，显示“已修改”；不强制立即跳到下一处。
5. “忽略并下一处”不改像素，前往后续待检查项；可通过上一处/全部列表返回并取消忽略。前后导航可以查看已修改/已忽略项，不等同于忽略。
6. “重新检查”重新采集现有图纸中的单格，包括本轮修改产生的新单格；保留本轮仍与位置和原色号匹配的忽略项。

忽略仅本轮有效，关闭面板结束该轮后清空，不写入草稿。已改成另一种颜色但仍为孤点的原目标会显示“已修改”；其新颜色需通过重新检查进入新清单。撤销恢复原目标后，状态也重新计算。

## 3. 自动修复：预览与确认

### 3.1 两步确认

- 点击“自动修复预览”，先适配全图，标记所有尚未修改且未忽略的单格，而非只标记默认勾选项。
- 全图目标格继续显示原色；描边区分已勾选（粉色）与未勾选/需手动处理（橙色），角标表示建议色或擦除。
- 面板逐项显示原色→建议色/擦除、列行位置、建议依据及勾选框。可取消默认勾选，也可主动选中唯一最多但未过半的建议；并列或末颗保护项不可勾选。
- 点击“确认修复N处”才修改。零项禁用确认；已忽略项不进入本批次。
- 预览期间以遮罩屏蔽背后鼠标操作，模态语义阻止工具快捷键，Tab限制在面板内；Esc或关闭按钮先取消预览，回到普通排查。
- 取消不改像素，恢复进入预览前的镜头。确认应用后保持全图供核对，仍可逐处导航。

### 3.2 3×3投票规则

| 周围有效邻居情况（排除中心） | 行为 |
| --- | --- |
| 某色唯一最多且严格超过有效邻居的一半 | 建议该色，默认勾选 |
| 某色唯一最多但未过半 | 给出建议，默认不勾选，可手动勾选 |
| 最多数量并列 | 仅手动处理，不擅自挑色 |
| 没有任何有效颜色 | 建议擦除，默认勾选，但服从末颗保护 |

例：5红/2蓝/1白，推荐红；4红/3蓝/1白，红色为未过半建议；4红/4蓝，留给人工确认。透明格不投票，也不被当作替换颜色。

全部建议基于同一份修复前快照计算，再统一应用，不能边计算边改图。只执行一轮，不进行连锁迭代。例如两颗相邻且异色的孤点可能互换颜色后仍为孤点，不能宣称所有单格已被消除；面板提示完成后可重新检查，结果文案为“已应用N处修改”。

### 3.3 最后一颗豆子

- 任何批次不得把整张图纸清空。
- 如果待擦除建议覆盖所有剩余实际格，保留一个目标并显示“至少保留一颗豆子，不自动擦除此格”。该项不允许勾选。
- 提交时再次计算剩余实际格数量，若仍会为空则整次拒绝，不部分写入。

### 3.4 数据、历史与过期保护

- 读取当前stagedPixelData，缺失时使用pixelData；确认时复核会话图纸身份、尺寸、镜像方向及完整像素签名。
- 连续操作中或快照变化后不得沿用旧建议；预览失效提示重新计算，不覆盖用户刚完成的修改。
- 改色和擦除混合批次只记录一条全局撤销，完整保留每格原颜色字段，撤销/重做同步正式与暂存像素。
- 内存批量操作新增可选nextColors数组，与indices/prevColors逐项对应；旧单一nextColor格式继续兼容。mirrorEditorHistory重排索引后前后颜色对应关系仍保持。
- 忽略、定位、勾选、取消预览不写图纸撤销；排查状态和预览不写入草稿或导出，不自动保存。草稿和导出的持久化格式保持。

- 非目标实际格压暗从40%提高至72%。

### 4.2 PC色板拖动与保留弹窗

- 用户授权可拖动，覆盖旧“PC色板不可拖动”的规则。顶部空白可拖，按钮、输入与颜色列表不作为拖动区域。
- “图纸颜色/全部颜色”共享位置，切换标签保留；同一图纸关闭重开保留，跨图纸/端布局重置。位置在视口内，不写入草稿。
- 色板打开时按空格临时拖动画布，保持弹窗和眼睛高亮，松开恢复；搜索中的空格保留输入用途。显式关闭或选色后，空格释放不能恢复已关闭的色板工具。
- 用户随后要求直接拖动画布也保留弹窗，现已实施：PC画布区域点击不再触发色板外部关闭，色板工具状态下可直接平移，单击不编辑。
- 关闭按钮、Esc、选色及切换其他主工具仍沿用既定语义。PAD/手机保留原色板交互，没有推广PC拖动规则。
