### 2.3 Esc 分层语义

1. 有最上层弹窗/面板时，只关闭该层，适用时恢复打开前工具，不同时退出其他层。
2. 吸管或颜色替换等待时，取消等待，恢复之前工具，不丢弃已经完成的图纸修改。
3. 没有临时操作时，从画笔/橡皮等切换为拖动；已是拖动则不处理。
4. 正在绘制、拖动或中文组字时不切工具；空格临时模式下不额外用 Esc 打断。
5. 不调用会丢弃整个编辑暂存会话的 adjustCancel。删除确认通过现有“取消”按钮回调关闭，而非直接隐藏 DOM。

**尚需核查的边界**：当前输入控件保护在 Esc 分支之前，因此搜索/名称输入框内 Esc 也被忽略；对其他未知 role=dialog/dialog 对话框只阻断，不通用强行关闭。既定“关闭最上层”的完整行为还需结合真实焦点、嵌套面板、弹窗确认回调验收；不把这一边界当作已完成。

### 2.4 安全保护

- 输入名称、搜索色号及其他 input/textarea/select/contenteditable 内，不抢占工具键和文字自身的撤销重做。
- 中文组字（isComposing / keyCode 229）、已被其他处理器消费的事件、绘制/区域选择/平移/原图拖动/面板拖动/裁剪等手势期间，忽略键盘工具切换。
- 确认弹窗内不执行工具切换、图纸撤销重做或临时拖动；Esc 按取消语义处理支持的确认弹窗。
- 切工具、选色、镜像开关、临时拖动不应新增图纸编辑历史。本轮快捷键复用现有按钮和历史路径，没有改历史或草稿格式。

## 4. 本日最近色逻辑、动画和样式

- 最近色按色号去重，最多 5 色，最新置左；点击已有色也置左，空槽补位。记录来自真实选色，不把 UI 渲染或画笔绘制伪装成新选色。
- paintColor 为稳定当前绘制颜色，与 fillColor 等临时模式状态区分；初次画笔默认采用图纸最多色，只设置颜色，不改图，也不把图纸前三色伪装成最近历史。
- 切画笔/油漆/边框保留当前色，点击最近色保留子工具，返回画笔恢复 lastBrushTool。
- 草稿新增可选 colorSelection，兼容旧草稿；缓存键 perler_beads_color_selection_v1，按图纸身份保留最近选色/当前色/画笔子工具，最多 50 份，时间戳单调用于新旧选择。
- 刷新后重新打开同一草稿可恢复最近色；不是自动恢复刷新前尚未保存的整张图纸。新图纸/更换图片清空。
- 最近色方案 3：保留最近排序，让被选色滑到第一位，其余让位；不采用固定常用槽及复杂淘汰策略。
- FLIP 动画按颜色身份定位，移动约 360ms；选中色抬升最终为 2px（由 8px 减少）；新色淡入约 240ms。相同排序的刷新不重播，跨图纸和系统减少动态效果时跳过。
- 未选中浅色识别：实际色相描边、深色色号；亮度 >200 加 1px rgba(160,166,179,.45) 外轮廓。选中态文字/勾按明暗保证对比，用户认可效果。
- Figma 423:917 实读：选中胶囊 40×28、圆角 14；两层 DROP_SHADOW，同底色 60%/radius 8、黑色 10%/radius 4，偏移和扩展均为 0。
- 已用 box-shadow 替换旧 drop-shadow(0 4px 2px #D9B9C5)，颜色用 color-mix 跟随当前 chip-color；悬停轻微 brightness(.98)，按下阴影保留并叠加内光圈。
- 浏览器计算样式核对双色阴影通过，10 项既有选色/动画测试通过；用户认可“先这样”。
