# 开发归档：自动恢复、导出保存与离开保护

时间：2026-10-05 22:05（Asia/Shanghai）

## 1. 功能变更

- 每五分钟检查并自动保存未手动保存的图纸进度；每张图纸仅一份，持续覆盖，独立于手动草稿及最近10个版本。无变化跳过，连续绘制、恢复、保存、弹窗期间延后；后台暂停检查。
- 本地 IndexedDB 使用 kind=autosave 区分自动记录，手动列表/导出排除自动记录。恢复区显示时间；当前正在编辑时要求先保存或退出，避免覆盖编辑。
- 手动保存成功清理对应自动记录，失败保留；自动恢复继续关联原草稿，没有正式身份的记录首次手动保存才建立草稿。自动保存失败有提示，保留图纸与上次成功记录。
- 保存图片/镜像图发起下载后自动更新正式草稿，使用与保存一致的暂存像素；内容未变不新增版本。保存原图仍只下载。失败不伪造已保存，不阻断已发起下载；下载开始不等于磁盘保存成功。
- 页面内返回保留保存并返回、不保存返回、取消；判断与最新版手动保存内容比较，自动恢复记录不取消未保存提醒。
- 刷新/关闭使用 beforeunload 请求浏览器原生提醒，不在关闭时异步强行保存。

## 2. 本轮确认与后续规划

- 用户同意先搁置 Codex 内置浏览器刷新无响应问题，未保存保护要求不变。优先用 Chrome 验证刷新/关闭；不关闭保护，不把内置问题记成已修复。
- 恢复记录讨论留待后续：首页管理各张图纸，编辑页草稿针对当前图纸和版本；自动记录独立且每图纸一份。首页/编辑页列表拆分尚未开发。
- 缩略图为图纸数据绘制的 PNG；手动历史不重复存缩略图，自动记录当前不存缩略图。查看大图建议按需渲染数据，无需额外保存大图，尚未实施。
- 当前不保存返回仍保留自动记录；是否将明确放弃操作与自动记录清理关联，需要后续明确，不在归档时删除数据。
- 正式 index 生成方案继续保留，“中强度区域级扁平化＋主体与背景分离”仍暂时放弃；另存为入口仍暂时移除。

## 3. 刷新问题与验证结论更正

- 用户确认 Chrome 正常提供未保存提醒；Codex 内置浏览器点击刷新可能无响应。
- 独立极简页面仅注册 preventDefault 与非空 returnValue，同样复现未重载、未捕获确认框，排除本项目图纸状态逻辑作为必要原因。公开 UA 与普通 Chrome 相同，未发现可靠 Codex 特征。
- 此证据说明内置宿主处理离开确认存在兼容问题，但未确认具体宿主源码原因或修复方式。项目内没有实现能同时保留要求并修复内置刷新行为的方案。
- 之前将未重载作为刷新保护验收成功的结论不准确，本归档明确更正。临时诊断页与独立测试标签已清理。
