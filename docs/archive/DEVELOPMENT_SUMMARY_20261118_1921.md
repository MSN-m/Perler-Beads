# 开发归档｜PC Alt/Option 临时吸色快捷键

归档时间：2026-11-18 19:21（Asia/Shanghai）。上一份归档：[手机版图纸编辑、色板和三端历史上限](DEVELOPMENT_SUMMARY_20261117_1722.md)。

## 功能变更

- 用户授权仅 PC 增加按住 Alt/Option 吸色。按住临时显示吸管，点击图纸实际格取色，可连续点击；松开恢复此前工具及子工具，保留新选色和最近颜色。原 I 吸管快捷键不变。
- 读取 `stagedPixelData || pixelData` 的实际颜色，通过既有 `getGridHitFromEvent` 换算坐标、`rememberPaintColor` 更新选色；不改变像素、图纸撤销或草稿格式。
- 使用工具快照恢复画笔、油漆、边框、拖动及橡皮等状态，保留边缘选区。图纸身份变化时不恢复旧快照；显式切换其他工具后不抢回旧工具。
- 捕获取色的鼠标按下及后续点击，避免先松 Alt/Option 再松鼠标时误上色或擦除。失焦/页面隐藏解除临时模式。
- 输入框、组字、弹窗、编辑手势、面板、色板、批量替换等待、空格临时平移期间不启用。PAD/手机不新增该快捷键。
- 吸管悬停提示补充用法，入口与 import map 更新资源版本以加载新代码。
