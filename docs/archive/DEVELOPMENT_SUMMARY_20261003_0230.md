## 2. 本轮功能变更

### 橡皮三个工具

- 普通橡皮支持按住连续擦除，补齐快速移动跳过的中间格；一次拖擦记录一次全局撤销。按下后不会因第一格变透明而误启动平移。
- 连续擦除期间锁定内容显示包围盒，结束后重新计算；防止擦图纸边缘时落点跳动。期间禁止滚轮缩放；处理失焦、触摸取消及双指切换的结束路径。
- 区域橡皮点击删除上下左右相连的同色区域，不包含对角邻接；移除拖框区域删除路径。
- 按颜色橡皮悬停高亮全图同色格，换格切换高亮，移出有效格或切工具清除；点击整色删除。
- 整区域/整色会清空图纸时整次拒绝；连续擦除保留最后一颗豆子并提示。
- 主橡皮入口恢复上次橡皮子工具。选色、悬停、工具切换不增加历史。
- 区域橡皮原 Ctrl+Z 失效源于鼠标点击结束后 fillSelection 未清空；初步修复后，本轮替换为纯连通区域点击路径，消除残留手势锁。

### 边框及工具互斥

- 从整色橡皮切到边框/画笔/油漆等时，旧 colorEraseMode 未清空，会抢先执行删除。setActiveEditorTool 现统一清理不兼容状态；画布点击同时核对当前工具和模式。
- 拖动/色板不执行画布编辑；临时工具恢复时重新渲染。
- 边框从 stagedPixelData（优先）计算；渲染时刷新边缘，撤销/重做不沿用过时位置。
- 仅点击高亮边缘才使用当前 paintColor 给整圈边缘上色；其他有效格弹窗提示。跳过 NONE，避免把已擦空的格子重新填上。
- 保持原有整图轮廓边缘计算语义，不改成局部同色区域边框。

### 模块缓存

- 用户先后出现 getThemeMutedColor/endEraserStroke 导出缺失报错。服务器与源码已有导出，但浏览器命中旧模块缓存。
- index.html 加入版本化 main.js 入口与共享模块 import map；当前版本标记为 20261003-tools-2，覆盖 state/editor/renderer/ui/utils/edge/adjust/delete/zoom。
- 相对路径统一解析到相同模块版本，尤其保证 AppState 为单一实例。后续修改模块时同步版本，不只给入口加参数。

## 3. 修改文件清单

业务与入口：

- index.html：模块版本与 import map。
- src/main.js：橡皮子工具入口、快捷键手势保护、临时工具恢复及结束事件。
- src/state.js：橡皮手势、悬停、click 抑制、上次子工具状态。
- src/editor.js：统一模式互斥、工具切换清高亮、新图纸重置橡皮临时状态。
- src/features/delete.js：安全删除、连通区域/整色操作、连续手势、高亮和提示。
- src/features/adjust.js：统一画布派发、区域删除路径替换、橡皮手势、边框当前色填圈。
- src/features/edge.js：使用当前暂存数据计算边缘。
- src/features/zoom.js：连续擦除期间不误启动平移或滚轮缩放。
- src/renderer.js：连续擦除稳定显示范围、整色悬停高亮、边缘刷新。
- src/ui.js：镜像操作前结束未完成的绘制/擦除手势。
- src/utils.js：共用 getEdgeBeadIndices。

新增测试：tests/area-erase-shortcuts.test.mjs、tests/eraser-tools.test.mjs、tests/editor-tool-conflicts.test.mjs。

文档：docs/PROJECT_CORE.md、docs/PRODUCT_GUARDRAILS.md、本归档。
