# 开发归档｜手机版图纸编辑、色板和三端历史上限

归档时间为 2026-11-17 17:22（Asia/Shanghai）。上一份归档为[手机页面底色、MARD 品牌选择与预览缩放](DEVELOPMENT_SUMMARY_20261116_2200.md)。本轮工作区基于提交 `f4f70e7`。

## 功能变更

### 手机版图纸编辑页

- 手机版编辑页按新版布局接入。从左到右为「画笔、吸管、色板、橡皮」，四个主栏图标使用 Figma 直接导出的 24 × 24 SVG。色板显示调色盘，选中态图标为白色。画笔、橡皮的二级工具沿用现有编辑逻辑。排查、编辑镜像、独立拖动工具在手机编辑页暂缓。[Figma 编辑页](https://www.figma.com/design/Eu710M0iVlAqdXBJb7Wzp1/%E6%8B%BC%E8%B1%86?node-id=803-282)
- 缩放比例、重置、撤销／重做在画布内部，避开标尺。顶尺高 20 CSS px，左尺宽 22 CSS px，刻度随图纸坐标和倍率更新。100% 为适配大小，重置只恢复视图。单指编辑，双指捏合缩放、同向移动平移，单指切入双指时回滚尚未提交的笔画或擦除。
- 新版编辑页更新了顶部导出按钮。独立「保存与分享」页沿用上一版手机适配。

### 手机版色板

- 改为带遮罩的底部弹窗。「图纸颜色」显示实际用量并支持升降序，每行仅三个按钮可操作。「全部颜色」保留品牌色板和色号搜索。点行内空白、滚动或点遮罩关闭都不触发画布编辑。[Figma 色板](https://www.figma.com/design/Eu710M0iVlAqdXBJb7Wzp1/%E6%8B%BC%E8%B1%86?node-id=869-451)
- 「取色」把颜色设为当前画笔色并加入最近颜色。顶部提示「已选中{色号}」约 2.4 秒收起。「查看」收起色板，画布高亮同色格，显示「已选中所有{色号}」。
- 「替换」高亮源色并提示「点击颜色替换{色号}」，从图纸取目标色后整批替换，记一条全局撤销。确认完成或取消后恢复原工具。查看和替换可用提示旁的按钮取消。

### 三端历史上限

- PC、PAD、手机都改为最多保留 3 个手动保存版本，含最新版。旧超限草稿在打开、未变保存或事务失败时保留完整历史，下一次内容有变化且成功提交时整理为最近 3 条。自动恢复独立，仍为每张图纸一条。
- 手机版历史记录底部弹窗已审阅，确认保留缩略图大图预览、恢复前确认和两区空状态。现有手机历史弹窗继续沿用，底部弹窗样式待实施。[Figma 历史记录](https://www.figma.com/design/Eu710M0iVlAqdXBJb7Wzp1/%E6%8B%BC%E8%B1%86?node-id=871-2112)

### 手机同网预览

- 8765 端口提供独立静态副本。手机看不到新版的原因是副本仍引用上一版资源。已同步本轮公开网页文件和主栏 SVG，页面样式和脚本使用对应版本参数。原地址刷新可加载更新，也可使用[带版本参数的手机预览](http://192.168.46.129:8765/?v=20261117-icons)。静态副本会在后续工作区改动时再次需要同步。此次同步保留原地址及其浏览器草稿存储。

## 验证与已知问题

- 最新 146 项自动测试通过，覆盖手机双指位移和切入时回滚、标尺绘制、色板操作、替换取消和整批撤销、旧历史不变保存及事务失败保护。
- 内置浏览器在 320 px 和 375 px 手机视口检查编辑布局、工具切换、缩放重置、撤销／重做、色板滚动和搜索、遮罩防误触、批量替换与撤销。原手机预览地址另实测新版编辑和色板，确认四个 Figma SVG 实际渲染为 24 × 24。
- 使用合成图纸在 PC、PAD、手机视口检查版本列表只显示同一组最近 3 条。在桌面视口验证了色板正常打开。
- 固定标尺的 PC 覆盖层在桌面视口可见，仍待专项检查顶部遮挡、数字密度及原图对照边界。手机固定标尺已接入，待在实机检查双指操作、刻度对齐及对照布局。PAD 固定标尺尚未同步。
- 手机和 PAD 的真实触控、iPhone Safari 的状态栏与回弹，以及自动恢复记录的实机恢复路径还需复验。测试使用隔离页面和示例，未写入用户草稿。
