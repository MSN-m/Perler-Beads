# 开发总结 2026-08-13 22:13

## 本轮目标

在不修改正式 `index.html` 生成流程的前提下，建立组合流程与完整八组策略的独立实验页面，并记录当前评测结论。

## 新增实验页面

### `combined-lab.html`

用于同条件对照以下四个阶段：

1. 原图；
2. 中强度区域扁平化中间图；
3. 当前正式生成器基准图纸；
4. 组合方案图纸。

组合方案目前执行：

`中强度区域扁平化 -> 主体保护型映射 -> 品牌色板匹配 -> 颜色限制 -> 小色块清理`

其中“主体保护型映射”使用角落背景色估计，并将边缘明显或与背景色差较大的像素作为主体候选。它不是完整的主体分割，也不代表最终“主体/背景分离”方案。

### `algorithm-lab-complete.html`

保留原 `algorithm-lab.html` 不变，新增独立的八组策略实验页。

原页面中的半成品策略在新页提供了启发式独立实现：

- 主体与背景分离：背景色估计后，对主体和背景使用不同的网格取样权重；
- 全局颜色优化：先从全图选取共享色组，再映射每个网格；
- 形状优先生成：按高对比轮廓与内部区域分别取样；
- 可制作性优化：后处理小碎块和被同色包围的单格孔洞。

这些实现均为实验验证用途，不替换现有正式算法。

## 当前评测结论：未完成 / 未通过

用户已明确指出，新实验页面当前存在两项主要问题：

1. **颜色变乌**：输出颜色的亮度或饱和度出现不理想的下沉，未达到可接受的色彩还原。
2. **精准度不足**：主体细节、轮廓或整体图形还原仍不够准确。

因此，当前组合流程和完整八组策略页仅作为问题定位与对照工具保留；不得视作最终效果，不得接入正式生成、预览确认、草稿或导出流程。

## 后续排查方向

1. 分阶段对照原图、扁平化中间图、未限色网格、限色图纸，定位颜色发乌产生于扁平化、主体判断还是色板匹配阶段。
2. 对主体与背景策略增加可视化蒙版/分类预览，验证主体判定是否正确，再调整主体与背景的取样规则。
3. 使用人物、宠物、浅背景产品图、复杂背景图和透明 PNG 进行同条件评测，重点记录亮度、饱和度、轮廓、关键细节、碎色与耗时。
4. 只有颜色准确性和还原精准度达到可接受标准，并完成与正式编辑、草稿和导出兼容性验证后，才申请接入正式流程。
