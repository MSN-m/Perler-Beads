## 2. 已确认逻辑与实现

### 2.1 PC保存与草稿记录独立入口

- 按Figma 569:208拆成保存草稿按钮和独立草稿按钮；保存约100×40，草稿约40×40，间距20px，采用本地Figma SVG。
- PC点击保存仅保存，不自动打开记录；草稿按钮打开原居中记录弹窗，不改为抽屉。首页管理及PAD/手机既有保存后展示流程保留。
- 草稿按钮激活由记录弹窗开关驱动：打开主色底白字白图标，关闭恢复，与镜像状态互不影响。
- 保存事务沿用原身份、未变去重、5版历史及失败保护，不增加普通草稿条目。

### 2.2 保存反馈与加载动画

- PC保存中显示“保存中…”并禁重复点击；成功至少显示1.5秒，实际事务更慢时等事务完成；随后“已保存”显示2秒，再恢复“保存草稿”。
- 保存失败立即恢复并提示，不为了最短时长延迟错误；工作图纸及旧历史保留。跨图纸不能显示旧图纸保存成功。
- 保存图标替换为2×2圆环矩阵：单环外径6px、最终线宽2px、间距2px；从主题浅灰到主色循环，顺时针左上→右上→右下→左下，周期1.2秒，错开0/.3/.6/.9秒。
- 动画仅在保存中显示；减少动态效果时静态主色。图标背景色#FE498D不是UI主色修改指令，既有主题保持。

### 2.3 PC编辑页原位改名

- 用户授权仅PC编辑页移除“编辑图纸”与生成设置入口，只保留修改图纸名称；生成阶段设置、PAD/手机原入口不变。
- 点击名称或常驻铅笔进入原位输入并全选，展示确认/取消；确认或Enter提交，取消或Esc还原，外部点击不自动提交。
- 最多40字符，确认时去首尾空格；空名称使用既有“未命名图纸”占位。中文组字Enter不提交。
- 未确认输入不写AppState；确认只改当前图纸名称，不自动保存、不改变像素或新增撤销。后续保存/导出读取正式名称。
- 图纸身份或PC布局切换取消旧输入，旧图纸输入不得写入新图纸。原入口代码保留供其他端使用，PC编辑态阻止误打开设置。

## 3. 图标尝试与明确回退

- 用户最初提供Desktop/Frame 34.png，后提供Desktop/小鸡.png及背景色#FE498D，希望解决Windows Chrome安装图标圆角，同时避免干扰Mac Chrome。
- 实际检查：两张原图2242×2148，均有透明通道；圆角版背景采样为RGB(254,73,141)，即#FE498D。
- 讨论的方案为普通any透明圆角版与不透明满底maskable版；两种purpose不按操作系统分流，系统选择、裁切、留白及旧安装图标缓存仍需实机验证。
- 使用内置图像生成工具制作过一张候选，要求保留原小鸡、满底粉色及安全边距；输出没有严格保持细节/主体范围，未采用。
- 曾临时加入maskable资源配置及更新图标查询版本；发现偏差后已精确撤回。用户随后要求放弃并回退，再次检查确认Manifest无diff、index图标引用仍为20261006-1，assets图标未写入/替换，无maskable新资产。
- 现有favicon64、Apple触控180及Manifest any192/512保持原状态。id/start_url均为./index.html、scope为./，未修改应用身份、清理IndexedDB、卸载应用或新增Service Worker。
- 失败生成候选留在工具生成目录，不被项目引用；未删除用户原图。不要把生成结果当成最终资产或恢复待办，也不要未经重新授权继续制作。
