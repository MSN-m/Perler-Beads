# 开发总结 2026-08-13 17:24

## 本轮确认的产品决策

- 图纸生成的后续正式方向确定为两段式组合方案：
  - 中强度区域级扁平化；
  - 主体与背景分离的拼豆化策略。
- 两者不是两个可互相替代的效果，而是串联步骤：

  `裁剪图像 -> 中强度区域级扁平化 -> 主体/背景/透明区域差异化处理 -> 网格采样与品牌色板匹配 -> 颜色限制和清理 -> 图纸渲染`

- 中强度扁平化的职责是减少纹理噪点、细碎区域和冗余颜色，同时保留主体的主要色面、明暗关系和边界。
- 主体与背景分离的职责是让主体侧重轮廓和关键细节保留，让背景侧重简化和实际可制作性。

页面步骤：

3. 生成图纸：以扁平化结果为输入，执行主体与背景分离、网格化、品牌色板匹配、颜色限制和小色块清理。
4. 查看图纸：按正式图纸形式展示网格、色号、颜色数、豆数和耗时。
