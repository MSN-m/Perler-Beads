## 3. 已确认交互与修复规则

### 3.1 单格排查

- 检测定义不变：仅八邻域无同色色号的实际单格，斜角同色不算落单，不增加小块/散碎区域检查。
- 打开排查或点击单格标签，将窗口定位到本轮第一个目标；上一处/下一处遍历本轮清单。
- 忽略仍是忽略并前往后续待检查项；回到忽略项可取消忽略。已修改项不允许通过忽略覆盖处理状态。
- 进度分母和自动页“共N处”均为本轮采集的全部目标数，忽略/修改不会缩减总数。
- PC紧凑面板不显示旧“重新检查”“全部列表”入口；关闭后重开会重新采集。新编辑产生的新单格不会自动扩充本轮清单，需要关闭重开。忽略仅本轮有效，不持久化。

### 3.2 自动排查与点击修复

- 点击自动标签适配全图，标记本轮仍待处理且未忽略的目标；预览不改像素，不再显示逐项勾选。
- 点击自动修复才统一应用当前建议；无可应用项禁用按钮。总数仍显示本轮全部目标，不等于实际应用数。
- 全部建议读取同一修复前快照，统一提交，不边改边计算，不连续迭代。相邻异色孤点可能交换后仍孤立，不能声称已消除全部孤点。

| 有效邻居情况 | PC当前行为 | PAD/手机保留行为 |
| --- | --- | --- |
| 唯一最多且过半 | 采用该色 | 默认勾选建议色 |
| 唯一最多但未过半 | 采用该色 | 默认不选，可手动勾选 |
| 最多数量并列 | 按固定空间顺序取首个有效邻色 | 需手动处理，无自动色建议 |
| 无任何有效邻色 | 建议擦除 | 建议擦除 |

- PC并列回退顺序：左、右、上、下、左上、右上、左下、右下。左格有实际颜色则直接使用，可取非最多的少数邻色；透明格和越界位置跳过，不能跨行绕回。
- 无邻色则擦除由用户最后明确确认；不要把有邻色的顺序回退错误写成擦除，也不要按中途建议改为保留无邻色目标。
- 末颗保护不变：若全部实际格都会擦除，保留一个目标；提交完整校验，不能清空图纸，不部分写入失败批次。
- 改色/擦除混合批次仍只记录一条全局撤销，兼容nextColors内存格式及镜像历史；不新增草稿字段、不自动保存。
- suggestRepairs新增可选resolveUncertain；默认false保持触控端旧行为，PC显式传true。

### 3.3 最终取舍：PC自动页允许继续操作

- 用户明确要求自动排查不限制缩放和其他工具。最终PC预览role=region、无aria-modal、不显示shield、不限制Tab；不要恢复开发中途的模态遮罩方案。
- 可以继续缩放、平移、画笔、吸管、橡皮、色板、撤销重做。点击自动标签时进行一次全图适配；之后手动操作或更新建议不再重置镜头，不自动切回单格页。
- 图纸像素变化时refreshDesktopPreview按当前快照更新本轮剩余目标建议与标记。已改色/擦除目标不被旧建议覆盖；撤销恢复后相应目标可重新进入待处理。
- 点击修复仍验证会话身份、网格尺寸、镜像方向、完整像素签名和手势忙碌状态；过期失败时更新建议并提示核对后再次点击，不沿用旧建议写入。
- PC与触控端切换、镜像方向或图纸身份变化结束旧会话。当前有效性以desktop布尔边界区分，手机与PAD之间保持同一旧流程，不应把文档表述扩为任意尺寸变化均关闭。
- PAD/手机旧预览保留遮罩、模态、Tab限制、逐项勾选与取消恢复镜头；本轮没有把非模态策略推广过去。
