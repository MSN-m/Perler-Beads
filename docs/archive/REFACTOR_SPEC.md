# 拼豆图纸生成器 - 重构功能规格说明书 (REFACTOR_SPEC.md)

## 1. 项目概述
该项目是一个基于 Web 的拼豆（Perler Beads）图纸生成工具，支持将普通图片转换为拼豆像素图，并提供背景移除、颜色匹配、辅助线生成及导出功能。

## 2. 核心工作流
1. **首页 (Home)**: 上传图片或选择示例。
2. **设置 (Settings)**: 调整网格密度、移除背景、选择拼豆品牌和颜色套装。
3. **预览 (Editor)**: 交互式预览生成结果，支持缩放、平移和颜色高亮。
4. **导出 (Export)**: 生成带颜色清单的 PNG 预览图或矢量 SVG 文件。

## 3. 详细功能点清单

### 3.1 图像预处理 (Step 1 & 2)
- **上传功能**: 支持本地文件选择、拖拽上传。
- **示例加载**: 提供 3 个预设示例图片。
- **背景移除 (核心功能)**:
  - **点击移除**: 基于洪泛算法 (Flood Fill) 的点击区域透明化。
  - **容差调节**: 支持 0-100 的颜色容差调节。
  - **碎片清理**: 一键清除小于 15 像素的孤立透明碎点。
  - **撤销功能**: 支持最近 10 次移除操作的撤销。

### 3.2 图像像素化算法 (Step 2)
- **密度控制**: 滑动条调节 (10-104格)，保持原图比例。
- **拼豆板同步**:
  - 图案最大维度 ≤ 52: 使用 **52小板** (蓝色标签)。
  - 图案最大维度 > 52: 使用 **104大板** (紫色标签)。
- **颜色限制 (Median Cut)**:
  - 可选开启颜色限制。
  - 支持调节最大颜色数 (2-128)。
  - 使用中值切分法进行颜色量化。
- **抖动算法 (Dithering)**:
  - 可选开启 Floyd-Steinberg 误差扩散算法，提升视觉细节。

### 3.3 颜色匹配逻辑
- **品牌选择**: 支持 MARD, Artkal, Perler, Hama。
- **MARD 套装过滤**:
  - 支持 24, 48, 72, 96, 120, 144, 216, 264 色套装过滤。
  - 特定套装 (216/264) 的排除色逻辑。
- **匹配算法**: 使用 **Redmean 距离算法** (符合人眼感知) 将像素映射至最接近的拼豆色号。

### 3.4 交互式预览 (Step 3)
- **Canvas 渲染**:
  - 绘制 1:1 像素色块。
  - **标尺**: 顶部和左侧显示 1-52/104 的数字标尺。
  - **网格线**: 基础细网格线。
  - **辅助线**:
    - 5格/10格辅助线（虚线/实线）。
    - **出血线**: 52板为第2/50格，104板为第4/100格，显示为加粗实线。
  - **ID 标识**: 每个格子上根据背景深浅显示对比色 ID。
- **缩放与平移**:
  - 支持鼠标滚轮缩放（以鼠标点为中心）。
  - 支持鼠标拖拽平移。
  - 支持移动端双指缩放及单指平移。
  - **重置视图**: 一键恢复居中适配视图。
- **颜色统计与高亮**:
  - 实时显示总颗数和颜色种类数。
  - 点击底栏颜色块，画布同步高亮该颜色的所有像素，并降低其他区域亮度。

### 3.5 导出功能 (Step 4)
- **PNG 导出**:
  - 生成高分辨率长图。
  - 包含完整图纸（带标尺、网格、辅助线、ID）。
  - **颜色清单**: 底部生成胶囊风格的颜色列表，包含色块 ID 和所需颗数统计。
  - 列表文字垂直居中对齐，标题显示颜色总数。
- **SVG 导出**:
  - 生成矢量圆点（拼豆形状）图纸。

## 4. 关键 UI 细节
- **响应式布局**: 适配移动端，使用 Tailwind CSS 构建。
- **视觉反馈**: 按钮点击缩放效果 (`active:scale-95`)，过渡动画。
- **Tailwind 稳定性**: 包含 CDN 回退机制，防止主脚本加载失败。
