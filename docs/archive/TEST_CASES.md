# 拼豆图纸生成器 - 重构验证测试用例 (TEST_CASES.md)

## 1. 基础功能测试

| 编号 | 测试模块 | 测试步骤 | 预期结果 |
| :--- | :--- | :--- | :--- |
| TC-01 | 图片上传 | 1. 点击上传按钮选择本地图片<br>2. 拖拽图片到首页区域 | 成功进入 Step 2，预览区域显示上传的图片 |
| TC-02 | 示例加载 | 点击“小狗”、“花朵”或“像素风”示例 | 成功加载对应的本地图片并进入 Step 2 |
| TC-03 | 步骤切换 | 点击“下一步”、“返回”按钮 | 页面平滑切换，Step 状态正确（1-4） |

## 2. 图像处理与算法测试

| 编号 | 测试模块 | 测试步骤 | 预期结果 |
| :--- | :--- | :--- | :--- |
| TC-04 | 背景移除 | 1. 开启“移除模式”<br>2. 点击图片背景区域<br>3. 调节容差并再次点击 | 背景区域变为透明网格，容差越大移除范围越广 |
| TC-05 | 碎片清理 | 点击“清理残留碎点” | 孤立的小像素点（<15px）被清除 |
| TC-06 | 撤销功能 | 执行多次背景移除后点击“撤销” | 图片恢复到上一步移除前的状态，最多支持10步 |
| TC-07 | 密度同步 | 拖动像素密度滑动条 | 1. 密度数值更新<br>2. 当最大维度 ≤ 52 显示“52小板”<br>3. 当最大维度 > 52 显示“104大板” |
| TC-08 | 颜色量化 | 开启“颜色限制”，调节最大颜色数 | 生成图纸后，颜色清单中的颜色总数不超过设定值 |
| TC-09 | 抖动算法 | 开启/关闭“抖动算法”生成图纸 | 开启时渐变区域过渡更平滑，关闭时颜色块边缘更整齐 |

## 3. 预览交互测试

| 编号 | 测试模块 | 测试步骤 | 预期结果 |
| :--- | :--- | :--- | :--- |
| TC-10 | 画布缩放 | 1. 鼠标滚轮缩放<br>2. 移动端双指捏合 | 画布以焦点为中心缩放，文字 ID 随之缩放 |
| TC-11 | 画布平移 | 1. 鼠标按住拖拽<br>2. 移动端单指拖拽 | 画布随手指/鼠标平移，无卡顿 |
| TC-12 | 视图重置 | 点击右下角“重置视图”图标 | 画布恢复居中适配状态，图标消失 |
| TC-13 | 辅助线检查 | 观察 52/104 画布边缘 | 1. 边缘有加粗实线（出血线）<br>2. 每10格有加粗实线<br>3. 每5格有虚线 |
| TC-14 | 颜色高亮 | 点击底部颜色清单项 | 画布仅高亮该颜色，其他区域变暗；点击同一颜色取消高亮 |

## 4. 导出验证测试

| 编号 | 测试模块 | 测试步骤 | 预期结果 |
| :--- | :--- | :--- | :--- |
| TC-15 | PNG 导出 | 点击“保存图片” | 下载 PNG 文件，底部包含颜色清单，ID 和数量统计清晰对齐 |
