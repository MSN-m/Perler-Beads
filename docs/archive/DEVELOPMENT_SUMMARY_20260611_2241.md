## 功能变更

### 1. 编辑模式透明区域拖拽平移

- 在 `填色 / 移除底色 / 删除色块` 模式下，允许从透明格子或画布空白处拖拽移动图纸。
- 拖拽后会屏蔽紧随其后的点击事件，避免平移后误填色。
- 填色模式支持点击透明格子填入当前选中颜色。
- 保留“从有颜色格子开始”的框选填色能力；透明格子起手仍用于平移。

### 2. 色盘功能

- 工作台编辑工具栏新增/完善 `色盘` 功能。
- 可查看当前品牌、规格下的所有可用颜色。
- 点击色盘颜色后进入填色模式，关闭色盘面板，并在画板上使用该颜色填色。
- 色盘颜色按钮使用 `pointerdown` 优先触发，`click` 仅作为兜底，避免动态浮层重绘导致点击被吞。
- 色盘面板支持拖拽移动：
  - 拖拽标题区域移动。
  - 搜索框和关闭按钮不触发拖拽。
  - 拖拽范围覆盖整个工作台主画布区域，可跨越“原图对照”和“图纸”两个区域。
- 色盘按色号首字母分组展示，例如 `A / B / C / D ...`。
- 色盘位置保存在运行时状态中；换图、重新生成、恢复草稿、重置图纸时重置回默认位置。

### 3. 草稿恢复稳定性

- 修复点击草稿 `恢复` 无反应的问题。
- 草稿操作按钮改为 `pointerdown` 直接执行，避免输入框失焦、列表重绘后吞掉后续 `click`。
- 草稿操作按钮保留 `click` 兜底，并增加防重复触发窗口。
- 草稿名输入框补充 `id/name/type/autocomplete`，解决浏览器 Autofill 警告。
- 恢复草稿时补齐状态清理：
  - 编辑态
  - 填色态
  - 色盘状态
  - 质量检查覆盖层
  - 框选状态
  - 背景移除状态
  - 对照图状态
- 草稿原图加载失败时仍继续恢复图纸，不再卡住。

### 4. 图纸质量检查 MVP

- 工作台工具栏新增 `质量检查（n）`。
- 当前支持检测两类问题：
  - `颜色散碎`
  - `独立色块 / 少量独立色块`
- 点击质量检查后在画布上显示编号标记。
- 编号与问题列表对应，帮助用户定位问题区域。
- 检测逻辑采用规则启发式：
  - 小连通块识别独立色块。
  - 滑窗统计颜色复杂度识别颜色散碎区域。
- 暂不做自动修复，避免误伤图纸。

### 5. 收起/展开编辑工具栏

- 现阶段隐藏编辑工具栏的收起/展开入口。
- 保留底层状态字段，后续如有需要可重新启用。

## 已知 Bug / 当前风险

### 1. 色盘与动态浮层事件稳定性

已修复本轮发现的问题，但后续新增动态浮层时仍需遵守事件规则：

- 不要只依赖 `click`。
- 对动态列表/浮层关键按钮优先使用 `pointerdown` 执行动作。
- `click` 只作为键盘操作或兜底。
- 避免事件过程中重绘父容器。

### 2. 质量检查规则仍需调参

当前检测是 MVP：

- 颜色散碎阈值可能需要根据真实图纸继续调。
- 小连通块检测只按同色连通块判断，暂未结合原图语义。
- 暂无“忽略问题”“查看某一条自动定位”“自动优化”等能力。

### 3. GitHub Pages 部署注意

项目可作为纯前端部署到 GitHub Pages。

当前注意点：

- 默认入口仍是 `index.html`。
- 新工作台在 `workbench.html`。
- 如果希望线上默认进入新版工作台，需要后续决定：
  - 将 `workbench.html` 迁移/合并到 `index.html`；或
  - 让 `index.html` 跳转到 `workbench.html`。
- Tailwind CDN 会有生产环境警告，但不影响运行。

## 重要经验教训

### 动态 UI 事件规则

本轮多次出现“点击没有反应但没有报错”的问题，根因多与动态 DOM 重绘、输入框失焦、浮层隐藏有关。

后续规则：

1. 动态列表和浮层关键操作不要只绑定 `click`。
2. 优先使用 `pointerdown` 立即执行动作。
3. 保留 `click` 作为键盘/兜底路径。
4. 使用短时间窗口防重复触发。
5. 状态先更新，再统一刷新 UI。
6. 避免在事件链中途重绘父容器导致目标节点被销毁。

适用范围：

- 草稿列表
- 色盘颜色按钮
- 质量检查问题列表
- 后续任何浮层菜单或动态工具面板
