# Perler Beads 开发归档

## 本次状态

本阶段完成了编辑页 PC 端的视觉改版基础，并开始为后续 PAD 端适配保留独立调整空间。

## 已完成内容

- 编辑页背景统一为 `#E7EBEE`。
- 图纸增加柔和阴影，增强与工作区的层次关系。
- 编辑工具栏改为根据内部内容自适应宽度，不再使用固定宽度。
- 工具栏中的最近使用颜色暂时隐藏，为全部颜色入口腾出空间。
- 增加“全部颜色”工具入口及颜色弹窗。
- 全部颜色弹窗支持搜索和颜色列表渲染。
- 调整颜色清单的背景透明度、尺寸和内容居中方式。
- 按 Figma 提供的 SVG 更新保存、画笔、吸管、橡皮、颜色清单、重命名和设置等图标。
- 保存按钮拆分为保存图标与下拉箭头，并按设计要求设置间距。
- 工具栏和顶部操作区持续进行尺寸、线宽、背景及阴影校准。
- 已保留图纸名称、设置、颜色清单、草稿箱、导出等核心工作流。

## 当前已知问题

- “全部颜色”弹窗中的颜色点击行为仍未稳定验证，用户反馈点击后没有切换颜色、关闭弹窗或切换到画笔工具；浏览器控制台目前未出现对应业务报错，`favicon.ico 404` 与该问题无关。
- PAD 端尚未完成专项适配，当前布局仍主要沿用 PC/已有响应式规则。
- 工具栏、颜色弹窗、顶部操作区在不同 PAD 尺寸下的定位、可点击层级和空间占用还需要系统验证。
- Tailwind CDN 在个别网络环境可能出现加载失败，导致页面退化为无样式 HTML；这属于部署稳定性问题，需要后续处理。

## PAD 端适配步骤清单

1. 盘点现有断点、编辑页 DOM 层级和状态控制，明确 PAD 与 PC、手机的边界。
2. 以 `768x1024`、`834x1194`、`1024x768` 等典型尺寸建立测试基线。
3. 调整 PAD 顶部导航：保证标题、返回、保存、撤销/重做和导出完整可见且可点击。
4. 调整画布工作区：让图纸优先占据空间，支持双指缩放和拖动画布，避免被面板或工具栏遮挡。
5. 调整底部工具栏：按 PAD 横向空间重新分组，保证画笔、吸管、颜色、橡皮和全部颜色入口可操作。
6. 调整颜色清单与全部颜色弹窗：使用 PAD 合适的宽度、位置、层级和关闭方式，避免超出屏幕或被工具栏覆盖。
7. 调整设置与草稿箱：以弹窗或侧向面板呈现，打开时不破坏画布尺寸，关闭后恢复原布局。
8. 统一处理触控交互：点击、拖拽、双指手势、弹窗外点击和滚动区域之间不能互相抢事件。
9. 针对横屏、竖屏、分屏和浏览器地址栏变化做适配，检查 `100dvh`、安全区和底部工具栏位置。
10. 完成 PC、PAD、手机三组回归测试，重点覆盖生成、编辑、保存草稿、颜色高亮、颜色替换、导出和弹窗操作。

## 下一步安排

先完成第 1 至 3 步，建立 PAD 基础布局和顶部导航基线；随后处理画布与底部工具栏，再处理弹窗和触控事件。全部颜色点击问题会在 PAD 交互层梳理时一并定位，但不会扩大到无关功能重构。
