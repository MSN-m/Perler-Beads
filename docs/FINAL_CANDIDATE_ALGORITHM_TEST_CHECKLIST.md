## 每张图的检查项

### 1. 主体和边界

- [ ] 主体掩码完整：没有把主体误判为背景。
- [ ] 背景识别合理：没有把大面积背景误判为主体。
- [ ] 孔洞处理合理：必要孔洞保留，不产生错误填充。
- [ ] 轮廓连续、厚度稳定，没有明显断裂或多余边线。
- [ ] 透明或半透明边缘没有被错误吞掉或产生脏边。

### 2. 颜色和过渡

- [ ] 主体主色的明度、饱和度和色相接近原图。
- [ ] 没有明显发灰、发暗、发乌或脏色。
- [ ] 明暗关系可辨，深色区域没有全部压成一团。
- [ ] 渐变区域过渡自然，没有明显色带或突变。
- [ ] 候选算法的过渡不弱于正式基准。
- [ ] 色板颜色数量不超过设定上限，且颜色分配合理。

### 3. 细节和可制作性

- [ ] 人脸五官、宠物眼睛、商品标志等关键细节可识别。
- [ ] 细线、轮廓与主体结构没有不必要地消失。
- [ ] 没有明显孤立单格、碎点、断裂或伪孔洞。
- [ ] 背景已适度简化，但未破坏主体阅读性。
- [ ] 图纸整体适合实际拼制。

### 4. 与正式基准对照

- [ ] 候选的主体轮廓优于或不差于正式基准。
- [ ] 候选的颜色准确性优于或不差于正式基准。
- [ ] 候选的细节保留优于或不差于正式基准。
- [ ] 候选的碎色与孤立色块不多于正式基准。
- [ ] 候选没有以改善某一项为代价造成其他关键项明显退化。
