# 最终图纸生成算法：代表图测试任务

> 用途：为最终图纸生成算法建立稳定的人工测试集。每次调整实验候选算法后，可按本清单逐张复测；在未完成验收前，不接入正式生成流程。

## 测试图片类型

- 人物肖像：浅背景、复杂背景各 2 张。
- 宠物：短毛、长毛或高纹理毛发各 2 张。
- 商品／物件：浅色纯背景、透明 PNG 各 2 张。
- 风景：天空渐变、复杂自然背景各 2 张。
- 插画／卡通：纯色块、细线条风格各 2 张。
- 深色或低对比照片：主体与背景接近的图片 2 张。
- 高细节照片：建筑、花卉或多人场景 2 张。
- 透明素材：边缘半透明或浅色轮廓 PNG 2 张。

## 每张图片的记录项

1. 图片名称或编号。
2. 网格尺寸、品牌、颜色数。
3. 主体掩码是否正确。
4. 轮廓层是否连续、是否缺失或多余。
5. 正式基准与最终候选的对照结果。
6. 是否出现颜色偏灰、偏暗、色带或过渡不足。
7. 是否保留关键细节。
8. 是否出现碎点、孔洞、断裂或其他难以拼制的结构。

## 验收重点

- 颜色自然，无明显偏灰、偏暗或突兀色带。
- 主体不被背景误吞，轮廓保持完整。
- 关键细节在目标网格尺寸下仍可识别。
- 背景得到适度简化，不引入过多碎色。
- 最终候选整体优于正式基准，且没有以某一类图片的改善换取其他类别的明显退化。
