# 系统返回最小实验

本实验用于确定小红书原生顶部返回是否会执行网页历史后退。它不读写正式拼豆工具、草稿或用户文件，不申请权限，不联网，不拦截离开，也不插入用于困住用户的历史记录。

## 三种方式

- A：同一个 HTML，`replaceState` 建立第一页，`pushState` 进入第二/第三页，`popstate` 响应历史切换。
- B：同一个 HTML，通过 `location.hash` 进入各页，`hashchange` 响应切换。该方式进入第一页时会新增一条菜单历史，与A的根部退出次数不同；只用第二/第三页后退的结果作比较。
- C：两个真实 HTML 文件，以普通包内链接跳转。它是独立兼容性实验，不符合当前Skill采用的单页交付方式，不能当作合规正式包或直接送审。平台拒收或阻止包内跳转都是有效实验结果，不能以普通浏览器能跳转为由认定容器支持。

## 构建

在项目根目录运行 `python3 experiments/navigation-probe/build.py`。输出目录已存在时脚本拒绝覆盖。源码使用外置经典脚本与 ES2017，无运行时依赖。页面不会将正式应用导航改成实验行为。

## 本地检查的意义

本地浏览器可以验证记录建立、事件处理、按钮和包内链接。它不能验证小红书顶部系统返回。最终结论需要上传实际ZIP、在平台模拟器和Android/iOS真机分别操作。
